# motion-videos-claude-code

Programmatic motion graphics with [Remotion](https://www.remotion.dev) (4.0.535), set up for AI coding agents.
See `CLAUDE.md` for the agent guide.

```bash
npm install          # once
npm run studio       # live preview at http://localhost:3000
npm run render       # -> out/sample-showcase.mp4  (1920x1080, 30 fps)
```

Change resolution, fps and duration in `src/config.ts`. Register new videos in `src/Root.tsx`.

## Videos

| Composition | Format | Render |
|---|---|---|
| `SampleShowcase` | 1920×1080, 30 fps | `npm run render` |
| `GermanElection`: "German election system" explainer | 1080×1920, 30 fps, 30 s | `npm run render:german-election` (renders and masters audio to −14 LUFS) |

The German election video's voice-over, music and timeline are generated by `scripts/german-election/*.py`.
Script, storyboard and facts are in `briefs/german-election-system/`. The reusable brief template is `briefs/motion-video-brief.xlsx`.
