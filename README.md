# motion-videos-claude-code

Programmatic motion graphics with [Remotion](https://www.remotion.dev) (4.0.535), set up for AI coding agents.
See `CLAUDE.md` for the agent guide.

```bash
npm install          # once
npm run studio       # live preview at http://localhost:3000
npm run render       # -> out/sample-showcase.mp4  (1920x1080, 30 fps)
```

Change resolution, fps and duration in `src/config.ts`. Register new videos in `src/Root.tsx`.

## Videos

| Composition | Format | Render |
|---|---|---|
| `SampleShowcase` | 1920×1080, 30 fps | `npm run render` |
| `GermanElection`: "German election system" explainer | 1080×1920, 30 fps, 30 s | `npm run render:german-election` (renders and masters audio to −14 LUFS) |
| `WhyFranceVotesTwice`: "Why France votes twice" | 1080×1920, 30 fps, 39 s | `npm run render:final -- WhyFranceVotesTwice why-france-votes-twice` |
| `DutchElection`: "Dutch election system" (white explainer look) | 1080×1920, 30 fps, 59 s | `npm run render:final -- DutchElection dutch-election-system` |
| `EUElectionPart1`: "EU election system", part 1 of 2 (Vote + Parliament) | 1080×1920, 30 fps, 59 s | `npm run render:final -- EUElectionPart1 eu-election-part-1` |
| `EUElectionPart2`: "EU election system", part 2 of 2 (Commission + Laws) | 1080×1920, 30 fps, 59 s | `npm run render:final -- EUElectionPart2 eu-election-part-2` |
| `UKElection`: "UK election system" | 1080×1920, 30 fps, 60 s | `npm run render:final -- UKElection uk-election-system` |
| `ItalianElection`: "Who runs Italy?" (Italian election system) | 1080×1920, 30 fps, 59.5 s | `npm run render:final -- ItalianElection italian-election-system` |
| `AustrianElection`: "Who runs Austria?" (Austrian election system) | 1080×1920, 30 fps, 59.6 s | `npm run render:final -- AustrianElection austrian-election-system` |

The German election video's voice-over, music and timeline are generated by `scripts/german-election/*.py`.
Newer videos use the shared tools: `scripts/voiceover.py` (AI voice + subtitle timing), `scripts/music.py`,
`scripts/sfx.py` and `scripts/render.sh` (render + master to −14 LUFS). See `CLAUDE.md`.
Scripts, storyboards and facts are in `briefs/<video>/`. The reusable brief template is `briefs/motion-video-brief.xlsx`.
